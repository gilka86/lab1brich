## Лабораторная работа №2
Добавлены страницы приложения и навигация с помощью React Router.
Реализовано:
- список заметок;
- карточки заметок;
- страница подробной информации;
- получение id заметки из URL;
- страница создания заметки-заглушка;
- общая навигация;
- обработка неизвестного адреса;
- обработка отсутствующей заметки;
- адаптивное отображение карточек.
### Проверка
1. Запустить `npm run dev` из папки `frontend`.
2. Открыть `/notes`.
3. Перейти на несколько страниц заметок.
4. Проверить прямое открытие `/notes/n1`.
5. Проверить `/notes/new`.
6. Проверить отсутствующую заметку `/notes/missing`.
7. Проверить неизвестный адрес `/unknown`.
8. Выполнить `npm run build`.
9. Выполнить `npm run preview`.
