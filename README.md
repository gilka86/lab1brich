
# Мои заметки

Учебное веб-приложение для управления заметками.

## Технологии

- React
- TypeScript
- Vite
- React Router

## Возможности

- Просмотр списка заметок
- Просмотр подробной информации
- Создание новой заметки
- Редактирование существующей заметки
- Удаление с подтверждением
- Фильтрация по статусу
- Проверка введённых данных

## Запуск

Установка зависимостей:

```bash
npm ci
```

Запуск приложения:

```bash
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Предварительный просмотр сборки:

```bash
npm run preview
```

## Хранение данных

Данные хранятся локально в состоянии React
с помощью useState.

После обновления страницы изменения исчезают,
и восстанавливаются исходные демонстрационные заметки.

## Лабораторная работа №3

Тема: Формы и локальное состояние приложения.

Реализованы:
- общий массив заметок в App;
- передача данных и функций через props;
- переиспользуемый компонент NoteForm;
- управляемые поля формы;
- валидация данных;
- операции создания, редактирования и удаления;
- фильтрация по статусу.
