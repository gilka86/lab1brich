## Запуск
Необходимы Node.js указанной версии и npm.
Из корня скачанного проекта выполните:
```bash
cd frontend
npm ci
npm run dev
```

Откройте в браузере адрес, который напечатает терминал.
Для остановки сервера нажмите Ctrl+C.

## Проверка типов и сборка
Находясь в папке frontend, выполните:
```bash
npm run build
```
Команда сначала проверяет TypeScript, затем создаёт сборку в frontend/dist.
Для просмотра готовой сборки:
```bash
npm run preview
```
Откройте адрес из терминала. Для остановки нажмите Ctrl+C.

## Лабораторная работа №2
В приложении добавлены страницы и навигация с использованием React Router.
### Страницы приложения
- `/` — перенаправление на список заметок
- `/notes` — список заметок
- `/notes/new` — страница создания заметки
- `/notes/:id` — страница подробной информации о заметке
- неизвестный адрес — страница «Страница не найдена»
### Демонстрационные данные
Все заметки в приложении являются демонстрационными и хранятся локально в проекте. Работа с сервером и базой данных на данном этапе не используется.

## Лабораторная работа №4. HTTP-запросы и работа со справочником категорий

**Цель работы:** освоить получение данных по HTTP с использованием `fetch`, обработку асинхронных операций и ошибок в React-приложении.

### Реализованные возможности

- Создан JSON-справочник категорий заметок.
- Реализована загрузка категорий через HTTP с использованием `fetch`.
- Добавлена проверка структуры полученного JSON и уникальности идентификаторов категорий.
- Создан пользовательский хук `useCategories` на основе `useState` и `useEffect`.
- Реализована отмена HTTP-запросов через `AbortController`.
- Добавлены состояния загрузки, ошибки и успешного получения данных.
- Реализована повторная загрузка категорий без потери введённых данных.
- Текстовое поле категории заменено выпадающим списком.
- Сохранение заметки блокируется при отсутствии доступной категории.

### Проведённое тестирование

Проверены успешная загрузка категорий, создание и редактирование заметок, отсутствие сети, пустой справочник, неправильная структура JSON, повторяющиеся идентификаторы и отмена HTTP-запросов.

Проверена обработка ответа HTML вместо ожидаемого JSON при запросе несуществующего файла.

Команда `npm run build` выполнена успешно. Собранное приложение проверено с помощью `npm run preview`.
